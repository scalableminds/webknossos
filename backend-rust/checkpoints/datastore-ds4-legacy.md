# DS4 legacy datastore API — Codex 2026-10-12

Status: DONE. Dedicated adapters implement the overrides in
`webknossos-datastore/conf/datastore.versioned.routes`: 56 versioned method/path
registrations plus the two unversioned dataset chunk compatibility registrations.
These are separate from the unchanged 132 latest registrations.

## Contracts

- Versions 10–14: proxy and Zarr2/Zarr3/experimental dataset/private-link
  datasource JSON recursively downgrades safe largest segment ID envelopes to
  plain numbers. Values above 2^53−1 remain bigint envelopes. Latest versions
  15–16 retain envelopes. Permissions, headers, body errors and private-link vs
  user tracingstore tokens are preserved. HEAD uses the same version override.
- Versions 10–13: old GET/POST dataset chunk endpoints, unfinished uploads,
  reserveUpload and finishUpload reuse existing authenticated upload flows with
  the old DTOs. Finish takes uploadId from its JSON body and returns newDatasetId;
  body needsConversion is validated but ignored. Legacy reservation similarly
  ignores conversion fields and reshapes resumable/name/org/team fields.
- Versions 10–11: authorized serial linked-layer resolution uses organizationId,
  then organizationName, then empty string; an existing ObjectId avoids WK
  lookup, directory names use findDatasetId. Missing layersToLink explicitly
  becomes an empty list, matching the Scala request serialization.
- Version 10 manual reserve: validates administrative access and reserves through
  WK with aManualUpload/zero files/isVirtual=false; creates no Redis/upload state.
- Unversioned GET/POST /data/datasets still serve old clients' chunk requests.
  Versions 14–16 do not alias their otherwise missing /datasets route to this
  compatibility endpoint. JSON limits and upload multipart limits stay distinct.

## Evidence

`tools/GenerateLegacyUploadFixtures.java`. Actual HTTP tests replay default,
optional/null, conversion, linked-layer and exact validation-error cases. The
oracle uses the actual Scala DTOs and reproduces controller adaptation; it does
not run a Play server. Fixture README documents the exported Scala classpath.

Actual router tests exercise versions 10–16 proxy/dataset/private-link metadata,
all old reserve/chunk/finish contracts, unversioned chunks, manual reserve,
unfinished uploads, denied lookup/manual requests, HEAD, invalid binders and
missing newer chunk routes. They preserve current-token forwarding and avoid
source/lookup/Redis effects on denial or JSON validation failure.
