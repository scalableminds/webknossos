### Changed
- Reworked the segment rows in the Segments tab: the mesh state of a segment is now shown as a chip within its row instead of a separate child row, the segment actions appear in the row on hover, the active segment is marked with a colored bar and the segment centered in the viewports by its crosshair button (both replacing icons in the row), and group rows show how many segments they contain.
- Loading a mesh from a segment row now offers the precomputed and the ad-hoc variant whenever a mesh file is available, instead of always computing ad-hoc.
- Segments are now renamed by double-clicking their name or via the context menu, which also shows the segment ID and offers the mesh actions that the mesh row used to provide.
