### Changed
- Modal dialogs are now consistent with each other. Widths come from a shared `ModalWidth` scale in `theme.ts` instead of 16 different ad-hoc values, modal title size and line height are pinned as antd design tokens rather than inherited from the `Typography` heading scale, and the OK button is spelled "OK" everywhere. Some dialogs change size slightly as a result: the delete-group dialog and the terms-of-service dialog get a little narrower, the create-animation dialog narrows from 900px to 800px, and several 500px dialogs widen to antd's 520px default. The merger-mode dialog is now top-aligned like every other modal, and the transfer-task dialog's buttons follow the usual Cancel-then-confirm order.
- Confirmation dialogs no longer show a yellow warning icon. antd colors the `confirm` icon with the warning color because one CSS rule covers both `confirm` and `warning`; that rule is now scoped to the WEBKNOSSOS blue, so an ordinary question no longer looks like a warning. Error and info dialogs keep their own colors, and warning styling elsewhere in the app is unchanged.
- Dialogs that hold unsaved input (forms, the script and markdown editors, the shortcut configuration, …) no longer close when clicking the backdrop, so a stray click cannot discard what you typed. Confirmation dialogs stay dismissible.
- In the task creation result dialog, "Download failed task info as CSV" moved from the middle of the dialog body into the footer, next to the OK button.
- In the "Create New Annotation" dialog, the "Create Annotation" button moved from the bottom of the dialog body into the footer.

### Fixed
- Several confirmation dialogs that previously rendered without any heading now have one, including "finish annotation", "reset task", "archive annotations", "delete segment data" and the dataset upload errors.
- The "request a new task" dialog showed the question and the hint about the next project run together on one line; they are now separate.
- The post-upload and duplicate-annotation dialogs no longer render their message as an oversized centered pseudo-heading.
