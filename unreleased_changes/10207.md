### Added
- Added a tool to register the layers of a dataset to one primary layer by placing matching landmarks side by side, similar to BigWarp. The landmarks of all layers are stored in one layer registration annotation, and the resulting transforms can be applied to the dataset. Open it via "Register Layers…" in the context menu of a dataset in the dashboard or in the menu of a layer in the viewer, or via "Register Layers" in the dataset settings. The composition wizard and the dialog shown after adding a dataset point to it as well.

### Changed
- When composing datasets with an affine transformation, landmarks that all lie in a single x, y or z slice are now supported directly. The transformation is fitted within that slice, and along the axis of the slice it only shifts the dataset. Before, only landmarks in a single z slice were supported, after confirming a dialog.
