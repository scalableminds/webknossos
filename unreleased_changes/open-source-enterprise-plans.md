### Added
- Added the "Open-Source" and "Enterprise" pricing plans. Open-Source unlocks the same features as Personal. Enterprise unlocks all features of Power with unlimited users and storage.

### Removed
- Removed the "Custom" pricing plan. Existing organizations on the Custom plan are migrated to the Enterprise plan, which is now also the default for organizations created on self-hosted instances.
