### Changed
- Nunito is now shipped as woff2 instead of TTF, reducing the font payload from 543 KB to 207 KB. Bold text now uses the font's real weight axis instead of being synthesized by the browser, which slightly changes its appearance and advance widths.
- Losslessly recompressed the bundled PNG and JPEG assets, reducing them from 6.0 MB to 4.4 MB without any change in image quality.

### Fixed
- Fixed the bucket-data web workers bundling ~350 KB of unused main-thread UI code (react-dom, antd and the error reporter), reducing the largest worker from 703 KB to 350 KB.

### Removed
- Removed the unused `process` dependency.
