### Added
- Added a tool to align one layer of a dataset to another by placing matching landmarks in both layers side by side, similar to BigWarp. The landmarks are stored in an alignment annotation, and the resulting transform can be stored as the layer's default transform. Open it via "Align Layers…" in the context menu of a dataset in the dashboard.
