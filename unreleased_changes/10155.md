### Added
- Added a "Resume Last Annotation" action to datasets in the dashboard that opens your most recently modified annotation of the dataset. The neighboring actions were renamed to "Start New Annotation" and "Open in Viewer".

### Breaking Changes
- The `includeAnnotationCount` query parameter of `GET /api/datasets` was renamed to `includeAnnotationInfo`, since it now also returns `latestOwnAnnotationId`. Requests that still send `includeAnnotationCount` get no annotation info.
