### Added
- Added an MCP (Model Context Protocol) server at `/api/mcp`, so that AI agents such as Claude Code or Claude Desktop can work with a WEBKNOSSOS instance. It offers tools to create an API token for the WEBKNOSSOS Python library and to look up the documentation of that library. It is disabled by default, enable it with `features.mcpEnabled = true`. MCP clients connect via OAuth. When connecting, the user chooses one of three permission levels (read, create/modify, delete). Connected applications are listed in the account settings, where they can be disconnected. Logging out everywhere disconnects all of them.
