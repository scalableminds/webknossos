### Added
- While a modifier key temporarily switches the active tool (e.g., Shift in the brush tool switches to the segment picker), the actually active tool is additionally highlighted in the toolbar. This is especially helpful when cycling through tools with Shift+W.

### Changed
- The overwrite mode is now toggled with a single button that shows the current mode and is highlighted while only empty areas are overwritten. The overwrite-mode icons were redesigned.
- Tool buttons in the toolbar now show a highlighted border on hover.

### Fixed
- Fixed that the brush-size icon was clipped and that the overwrite-mode and restrict-floodfill icons were smaller than the other toolbar icons.
- Fixed that hovered elements in the navbar (e.g., the position field) only highlighted their top and bottom borders.
