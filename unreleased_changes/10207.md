### Added
- Added a tool to register the layers of a dataset to one fixed layer by placing matching landmarks side by side, similar to BigWarp. The landmarks of all layers are stored in one layer registration annotation, and the resulting transforms can be applied to the dataset. Open it via "Register Layers…" in the context menu of a dataset in the dashboard or in the menu of a layer in the viewer. The composition wizard and the dialog shown after adding a dataset point to it as well.
