### Changed
- For datasets with more than 4 layers, the memory of 4 layers is now shared by all layers, with a small minimum per layer. With the default GPU setting, the total GPU and RAM memory for layer data therefore stays the same up to 64 layers. Each layer can keep less data in memory, so coarser magnifications may be shown sooner when zooming out.
- With the "Low" and "High" GPU memory settings, each layer now keeps at most the configured amount of data on the GPU. Before, it could keep up to twice as much, depending on how the GPU textures were rounded.

### Fixed
- Fixed that datasets with many layers could fail to render with the error "Could not pack varying", depending on the GPU.
