### Added
- Added bookmarks to annotations. A bookmark stores the current view (position, rotation, zoom, 3D camera, layer settings, mappings and meshes) and can be restored from the bookmarks tab. Merging annotations keeps their bookmarks.
- Bookmarks are included in annotation downloads (NML and thumbnails) and restored when uploading a single annotation file.

### Changed
- Skeleton-only annotations are now downloaded as a zip file containing the NML (and bookmark thumbnails), like annotations with volume layers.

### Migration
- FossilDB now needs to be opened with additional column families `annotationBookmarks` and `annotationBookmarkThumbnails`.
- The annotation download routes (`/api/annotations/:id/download` and `/api/annotations/:typ/:id/download`) now return a zip file (`application/zip`) for skeleton-only annotations as well, instead of a plain NML file (`application/xml`). Scripts and API clients that download skeleton annotations and parse the response as NML need to extract the NML from the zip first.
