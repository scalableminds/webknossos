### Changed
- Reworked the segment rows in the Segments tab: the mesh state of a segment is now shown as a chip within its row instead of a separate child row, the segment actions appear in the row on hover, the segment centered in the viewports is marked with a colored bar instead of a crosshair icon, and group rows show how many segments they contain.
- Segments are now renamed by double-clicking their name or via the context menu, which also shows the segment ID and offers the mesh actions that the mesh row used to provide.
