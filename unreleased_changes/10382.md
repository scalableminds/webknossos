### Changed
- The native code of the datastore and tracingstore (bucket scanning, Compresso decompression, Draco mesh conversion) is now written in Rust instead of C++. [#10382](https://github.com/scalableminds/webknossos/pull/10382)

### Migration
- The system library `libdraco` is no longer needed by WEBKNOSSOS and can be uninstalled. Building WEBKNOSSOS from source requires Rust 1.88 or newer instead of CMake and the Draco headers, see [DEV_INSTALL.md](DEV_INSTALL.md).
