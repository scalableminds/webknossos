### Changed
- Creating the first tasks is simpler. While an organization has no task type or no project yet, the "Create Tasks" page shows the steps to take first. The task form preselects the task type and project when only one exists, and otherwise the ones used last.
- When creating a task type or project, the team is preselected if only one is available. New task types allow the view modes that fit their annotation type by default, and their description is optional.
