### Changed
- When precomputing meshes, the mapping can now be chosen in the popover. By default, meshes are computed without a mapping, which works with every mapping and is required for proofreading. Previously, the active mapping was used.
- When a precomputed mesh can't be loaded because no mesh file is active or the active mesh file doesn't match the active mapping, a dialog now offers to switch to a compatible mesh file or explains how to precompute one. Previously, loading precomputed meshes was disabled if no mesh file was active.
- When a mesh file is activated automatically, a mesh file that fits the active mapping is preferred: during proofreading or without an active mapping, one computed without a mapping; otherwise, one computed for the active mapping. Previously, the first mesh file was used.
