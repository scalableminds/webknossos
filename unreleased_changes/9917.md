### Changed
- While simultaneous editing (live collaboration) is enabled for an annotation, actions that change its set of layers (adding, deleting or converting an annotation layer, merging a volume layer with its fallback layer, importing a volume tracing) are now disabled in the UI with an explanation, instead of potentially causing conflicts. Restoring an older version of an annotation while simultaneous editing is enabled now asks for confirmation and reloads the page for all collaborators, including the user who triggered the restore.

### Fixed
- Fixed several update actions (e.g., editing a layer's name or the annotation's description, adding a segment index, or another collaborator changing the active mapping) not being incorporated correctly while simultaneous editing (live collaboration) is enabled, which could previously lead to the annotation getting out of sync and requiring a reload.
