### Added
- Added an MCP (Model Context Protocol) server at `/api/mcp`, so that AI agents can work with a WEBKNOSSOS instance. It offers tools to create a short-lived API token and to look up the documentation of the WEBKNOSSOS Python library. It is also packaged as an MCP Bundle (`.mcpb`) for one-click installation into Claude Desktop, see `tools/mcpb`.
- Added short-lived API tokens. They have the same permissions as the user they were created for, expire after one day (configurable via `silhouette.tokenAuthenticator.shortLivedExpiry`), are held in memory only, and are revoked when the user revokes their API token or logs out everywhere.

### Changed
- The WEBKNOSSOS API now also accepts an API token in the `Authorization: Bearer` header, in addition to the `X-Auth-Token` header.
