### Fixed
- Fixed that an unreadable `{"success":false,"message":"Authentication required"}` error toast was shown in addition to the "session expired" toast, e.g. after logging out in another tab. Unauthenticated and forbidden requests now return the same error format as all other errors.
- Fixed that a misleading "session expired" toast was shown for failed requests of users that were not logged in (e.g. a failed passkey login). The server's error message is shown instead.
