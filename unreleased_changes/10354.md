### Added
- Agglomerate skeletons can be compared to a reference mapping. Enable "Compare to Reference Mapping" in the settings of the segmentation layer and select the reference to see which edges were added (green) and removed (orange) compared to the reference agglomerate of the clicked segment.
- The front-end API method `api.data.getDataValue` has a new optional parameter `enforceUnmapped` to get the unmapped segment id even if an agglomerate mapping is applied by the server.
