### Added
- Added OME-Zarr (`.ozx`) as an export format in the TIFF and OME-Zarr export tab of the download dialog.

### Changed
- `POST /jobs/run/exportTiff` now takes an `exportFormat` parameter (`ome_tiff` | `tiff_stack` | `ome_zarr`) instead of the `asOmeTiff` boolean.

### Migration
- OME-Zarr export requires a webknossos-worker that supports the `.ozx` export format. Older workers would produce a TIFF stack under the `.ozx` name.
