### Added
- Added an MCP (Model Context Protocol) server at `/api/mcp`, so that AI agents can work with a WEBKNOSSOS instance. It offers tools to create a short-lived API token, to look up the documentation of the WEBKNOSSOS Python library, and to look up the [EM-Skills](https://github.com/yanchaoz/EM-Skills) collection of volume EM processing skills. It is also offered as an MCP Bundle (`.mcpb`) for one-click installation into Claude Desktop, downloadable from the account settings.
- Added short-lived API tokens. They act for the user they were created for, limited to the permissions that user grants to agents (see below), expire after one day (configurable via `silhouette.tokenAuthenticator.shortLivedExpiry`), are stored in the database, and are revoked when the user revokes their API token or logs out everywhere.
- Added scopes for short-lived tokens, so that agents can be restricted to e.g. reading datasets and writing annotations. Scopes are enforced centrally for all API routes and for datastore/tracingstore access, and are configured per MCP connection with three permission levels (read, create/modify, delete) in the account settings, where they are stored per user and take effect immediately, also for agents that are already running. Outstanding agent tokens can also be revoked there. Set `webKnossos.tokenScopes.enforced = false` to only log what would be denied.

### Changed
- The WEBKNOSSOS API now also accepts an API token in the `Authorization: Bearer` header, in addition to the `X-Auth-Token` header.
