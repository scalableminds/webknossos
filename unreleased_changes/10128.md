### Changed
- For datasets with more than 4 layers, the GPU and RAM memory for layer data no longer grows with the number of layers. Instead, the memory of 4 layers is shared by all layers. With many layers, each layer can therefore keep less data in memory, so coarser magnifications may be shown sooner when zooming out.
- With the "Low" and "High" GPU memory settings, each layer now keeps at most the configured amount of data on the GPU. Before, it could keep up to twice as much, depending on how the GPU textures were rounded.

### Fixed
- Fixed that datasets with many layers could fail to render with the error "Could not pack varying", depending on the GPU.
