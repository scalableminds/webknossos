### Fixed
- Fixed reading N5 datasets with compression type `raw`.
- Fixed adding remote S3 datasets that are addressed in virtual-hosted style (e.g. `https://my-bucket.s3.us-west-2.amazonaws.com/key`).
- Fixed reading S3 datasets from a custom endpoint whose host name contains no dot but states a port, e.g. `s3://localhost:9000/my-bucket/key` or `s3://minio:9000/my-bucket/key`.
- Fixed that directory listings for S3 datasets on a custom endpoint could ignore the trailing slash of the listing prefix.
- Zarr v3 datasets that use a codec WEBKNOSSOS cannot read now report an error naming the codec, instead of failing downstream.
